**Problems, surprises, unfinished items**
- **vnstock's 8-year cap is stateful.** One over-long request truncates every
  later call in the same process to the last 8 years, silently. The first probe
  run therefore reported "history starts 2018-09-24" for all five symbols, which
  was false. Fixed by probing sources with a 60-day window and fetching in
  4-year chunks; the same symbols then returned 3,722 rows back to 2011-10-21.
  Worth remembering: the wrong answer looked completely plausible.
- **Unregistered vnstock is 20 requests/minute, not the 60 the doc assumed.**
  Exceeding it aborts the run. Delay raised to 4s.
- **Two patches to the probe script silently did not apply** because `ruff
  format` had reflowed the exact text being matched; the run afterwards looked
  unchanged and I nearly reported the stale result. Now assert before writing.
- **CafeF does not adjust volume** — adjusted and unadjusted volume are
  identical on 100% of days. Blocker G1 confirmed and unsolved by this source.
- **ACB's pre-2020 history is absent from every CafeF bulk file** (it transferred
  HNX→HOSE on 2020-12-14). Blocker G4 is no longer theoretical.
- **No free source splits matched vs negotiated volume** (G12). This collides
  with a non-negotiable principle and needs Ben's decision.
- Not done, deliberately: no schema, no bulk download, no scraper.
