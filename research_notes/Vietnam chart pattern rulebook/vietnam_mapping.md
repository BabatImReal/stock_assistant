# Vietnam chart patterns: implementation and market mapping

## Which requested pattern families already have an equivalent deterministic feature?

### Takeaway
The branch has short candle and consolidation flags plus trend/strength context. None of the requested multiweek geometric formations has an equivalent detector. Existing flags can be inputs to those definitions, but are not substitutes for them.

### Cited Findings

- The source of truth originally makes 3–5-session patterns the main signal and longer formations background context; Ben's approved new scope expands the *research* to longer formations. Their definitions and observation horizons therefore need fresh registration before outcomes are examined. [Source-of-truth §1, §3](</Users/Ben Nguyen/stock_assistant/stock_assistant/docs/knowledge/pattern-research-knowledge.md>)
- The branch's `trend_stage` (MA50/MA200 and slope), `rs_index_20d/60d/120d`, and down-day relative strength address longer price behaviour, but not geometric chart formations. [Structural source](</Users/Ben Nguyen/stock_assistant/stock_assistant/src/vnstock_research/structural.py>)

### Inferences
- Define a small set of geometric primitives first (confirmed pivots, level or boundary lines, compression, impulse, breakout), then express the named families as fixed combinations. This reuses current pivots and trend/volume context and avoids treating diagram variants as independent discoveries.
- Keep a forming state separate from a confirmed event: repeatedly visible forming days are one evolving setup, not many independent successes. A failed breakout is an event in its own right, not a shape that must be retroactively erased.

### Gaps
- No multiweek detector or feature configuration was found by targeted search in `src/` and `config/rules/`; a complete catalogue still requires explicit Ben-reviewed definitions for each named family.
- The approved expansion has no fixed minimum/maximum formation duration, pivot confirmation width, touch tolerance, amplitude floor, precedence for overlapping labels, or confirmation/failure threshold.

## Does the existing fingerprint, forward-return and evidence infrastructure support long-form formations as-is?

### Takeaway
The existing bar, feature and evidence contracts can host a bounded trailing detector. The current 3/5-session outcome table and repeat-hit counting cannot by themselves answer whether a multiweek formation predicts a longer move or how often one *forming* setup succeeds.

### Cited Findings
- A measure declares every required prior row via `lookback`; the shared feature gate blanks windows crossing a trading gap, excluded row or factor defect. Asking for `matched_volume` also blanks spans whose volume cannot be adjusted. This supports a detector with a fixed maximum lookback and dated confirmation, provided its declaration covers every pivot-confirmation margin. [Feature base](</Users/Ben Nguyen/stock_assistant/stock_assistant/src/vnstock_research/features/base.py>) · [Existing pivot rule](</Users/Ben Nguyen/stock_assistant/stock_assistant/src/vnstock_research/features/trend.py>)
- Bars include adjusted OHLC and inverse-adjusted matched volume, raw OHLC for exchange price bands, dated/unknown exchange, trading-session gap, excluded window and factor-break flags. [Bar loader](</Users/Ben Nguyen/stock_assistant/stock_assistant/src/vnstock_research/features/bars.py>)
- The fingerprint stores all enabled feature columns by stock-day and refuses stale builds, rule code or feature-set parameters. The structural branch uses a distinct feature set to preserve the earlier registered one. [Fingerprint](</Users/Ben Nguyen/stock_assistant/stock_assistant/src/vnstock_research/patterns/fingerprint.py>) · [Structural source](</Users/Ben Nguyen/stock_assistant/stock_assistant/src/vnstock_research/structural.py>)
- `forward_returns.py` currently stores k=3/5 from next-session open to `t+1+k` close, with gross/net, MFE/MAE, actual resolution date, reasons for missing outcomes, ceiling-entry rejection and floor-exit deferral. Longer k values need separately fixed research rules and verification of the extended window; a configuration-only change would also change the existing returns rules hash. [Forward returns](</Users/Ben Nguyen/stock_assistant/stock_assistant/src/vnstock_research/backtest/forward_returns.py>) · [Pattern horizons](</Users/Ben Nguyen/stock_assistant/stock_assistant/config/rules/patterns.yaml>)
- The evidence gate joins the same adjustment build, excludes flagged/illiquid/unresolved outcomes, checks `known_on < query day`, compares a hit with the base rate on the same eligible population, and falls back stock → point-in-time liquidity tier → market at 30 de-clustered cases. Its current de-clustering is tied to outcome k, not formation lifespan. [Evidence source](</Users/Ben Nguyen/stock_assistant/stock_assistant/src/vnstock_research/backtest/evidence.py>)
- The 2024–2025 holdout was used for the existing registered tests; `history.yaml` explicitly labels those years spent and its outputs descriptive. New choices cannot claim independent historical confirmation there. [Validation note](</Users/Ben Nguyen/stock_assistant/stock_assistant/agent-memory/knowledge/validation.md>) · [History config](</Users/Ben Nguyen/stock_assistant/stock_assistant/config/rules/history.yaml>)

### Inferences
- A long-form formation can be added through the existing feature registry and fingerprint, with an immutable rule/version and finite maximum lookback. A dated confirmed flag is compatible with the existing evidence gate. Its *forming-to-confirmed probability*, event duration, repeated sightings, multiweek returns and bearish downside endpoints need explicit event and outcome definitions; the current boolean and k3/k5 statistics do not answer those questions.
- The first research tranche after rulebook approval should be: (1) record rule definitions and event-state conventions; (2) implement and check confirmed pivots/boundaries and one simple family such as double top/bottom with forming, confirmed and failed dates; (3) audit examples blind to outcomes; (4) run descriptive counts, missing-data/drop reasons and same-population base rates; (5) register only a bounded new hypothesis set for future observations. Reuse current bars/gates rather than building a separate pipeline.

### Gaps
- No untouched historical holdout remains for new pattern definitions. A forward-only confirmation period and minimum sample/decision date must be specified; current notes say the paper ledger has no forward rows, but that operational claim was not rechecked against the database here. [Current-state note](</Users/Ben Nguyen/stock_assistant/stock_assistant/agent-memory/CURRENT_STATE.md>)
- Ben must choose the research target: probability of a *confirmed* breakout rising/falling over fixed k, probability that a *forming* candidate confirms, or both; the two have different denominators. He must also choose suitable longer k windows, target-before-stop vs fixed exit, and what counts as bearish success. Existing k3/k5 and the provisional 0.15% broker fee were already registered for the earlier work. [Forward-return source](</Users/Ben Nguyen/stock_assistant/stock_assistant/src/vnstock_research/backtest/forward_returns.py>) · [Costs config](</Users/Ben Nguyen/stock_assistant/stock_assistant/config/rules/costs.yaml>)

## Which Vietnam data and market rules determine validity?

### Takeaway
Adjusted prices, genuinely matched volume, trading-session gaps, and point-in-time eligibility are essential to chart geometry. Exchange-specific price bands and especially UPCoM's reference-price method constrain any claim about tradeable outcomes.

### Cited Findings
- The primary CafeF bulk OHLCV volume was checked against 20 large negotiated-deal stock-days: it matched order-matched volume in 20/20 and matched-plus-deal in 0/20. The project adjusts volume by the inverse price factor, while backfilled spans without an adjustable factor remain unknown for volume research. [Data-source probe note](</Users/Ben Nguyen/stock_assistant/stock_assistant/agent-memory/knowledge/data-sources.md>) · [Bar loader](</Users/Ben Nguyen/stock_assistant/stock_assistant/src/vnstock_research/features/bars.py>)
- The data source includes some delisted stocks but unevenly: the probe found 82 former HOSE, 71 former HNX and 309 former UPCoM three-letter symbols; 37 of the HOSE group had under 50 bars and 11 were one-row stubs. Transfer history was missing for some symbols until a targeted backfill. This is residual survivorship/coverage risk, especially for long formations. [Data-source probe note](</Users/Ben Nguyen/stock_assistant/stock_assistant/agent-memory/knowledge/data-sources.md>) · [Open-questions G11](</Users/Ben Nguyen/stock_assistant/stock_assistant/agent-memory/knowledge/open-questions.md>)
- The currently configured liquidity rule is a **provisional** 1 billion VND/day matched traded-value floor over 60 market sessions, with at least 40 traded days. Point-in-time tiers avoid selecting only today's survivors. [Universe config](</Users/Ben Nguyen/stock_assistant/stock_assistant/config/rules/universe.yaml>) · [Universe source](</Users/Ben Nguyen/stock_assistant/stock_assistant/src/vnstock_research/data/universe.py>)
- HOSE's official price-band document states normal ±7% and ±20% for first trading or resumption after at least 25 consecutive sessions; the official HNX FAQ states ±10% for listed stocks and ±15% for UPCoM. HNX says UPCoM's reference is the previous session's weighted average of executed prices, unlike HNX's previous closing price. [HOSE price limits](https://staticfile.hsx.vn/Uploads/UploadDocuments/2372211/4.Price%20limit.pdf) · [HNX FAQ](https://web02.hnx.vn/vi-vn/hoi-dap.html)
- The current code computes UPCoM fillability using a prior-close-derived reference, marks it flagged, and excludes those returns from validated evidence; undated exchange membership is similarly flagged. This means a descriptive UPCoM shape can be observed, but the existing net-return gate does not validate a UPCoM trading edge. [Forward returns](</Users/Ben Nguyen/stock_assistant/stock_assistant/src/vnstock_research/backtest/forward_returns.py>) · [Evidence source](</Users/Ben Nguyen/stock_assistant/stock_assistant/src/vnstock_research/backtest/evidence.py>)
- `market_rules.yaml` labels early exchange bands/ticks unverified. An HNX annual report also documents a change in its listed-stock reference-price method in March 2012, so today's rule must not be projected mechanically backward. [Market-rule config](</Users/Ben Nguyen/stock_assistant/stock_assistant/config/rules/market_rules.yaml>) · [HNX 2012 annual report](https://owa.hnx.vn/ftp/PORTALNEW/PUBLICFACTBOOK_FA/20161220/HNX_Bao%20cao%20thuong%20nien_2012.pdf)
- `nightly_update.py` currently sets `restated = False` after computing only new-session factors; it does not compare historical factors when CafeF restates adjusted prices. Any new long-window measurement inherits that unresolved integrity risk. [Nightly source](</Users/Ben Nguyen/stock_assistant/stock_assistant/scripts/nightly_update.py>) · [Open-questions G2](</Users/Ben Nguyen/stock_assistant/stock_assistant/agent-memory/knowledge/open-questions.md>)
- The cost file uses a provisional 0.15% broker fee on each side plus 0.1% sale tax. The source-of-truth requires date-correct settlement, price limits, costs and no pattern/outcome across a trading gap. [Costs config](</Users/Ben Nguyen/stock_assistant/stock_assistant/config/rules/costs.yaml>) · [Source-of-truth §5.6, §8](</Users/Ben Nguyen/stock_assistant/stock_assistant/docs/knowledge/pattern-research-knowledge.md>)

### Inferences
- Prioritize the integrity checks before claiming any long-window edge: G2 restatement detection, formation windows covering every gap/factor defect, and verified historical exchange rules. Keep price-only geometry available where volume is unknown, but mark volume confirmation unknown rather than false.
- If UPCoM is in research scope, show shape frequencies and descriptive price outcomes separately until its dated reference-price series and fillability can be validated. A single pooled HOSE/HNX/UPCoM tradeability rate would misrepresent the current gate.

### Gaps
- The exact historical bands, tick sizes, special corporate-action sessions and reference-price changes by exchange/date are not fully verified from official primary documents. The live official pages above establish current selected rules, not the complete 2012–2026 chronology.
- Ben's actual broker fee, final liquidity floor, long-form outcome horizon and acceptable downside remain unresolved. [Open questions](</Users/Ben Nguyen/stock_assistant/stock_assistant/agent-memory/knowledge/open-questions.md>)
